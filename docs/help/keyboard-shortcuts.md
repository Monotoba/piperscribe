# Keyboard Shortcuts

## File Operations

| Shortcut | Action | Description |
|----------|--------|-------------|
| **Ctrl+N** | New Project | Create a new empty project |
| **Ctrl+O** | Open Project | Load an existing project file |
| **Ctrl+S** | Save Project | Save current project |
| **Ctrl+Shift+S** | Save Project As | Save project with new name |
| **Ctrl+I** | Import Document(s) | Import one or more documents (TXT, DOCX, PDF, Markdown, HTML) |
| **Ctrl+E** | Export Audio | Save generated audio as WAV file |
| **Ctrl+Q** | Quit | Exit PiperScribe |

## Editing

| Shortcut | Action | Description |
|----------|--------|-------------|
| **Ctrl+Z** | Undo | Undo last edit |
| **Ctrl+Y** | Redo | Redo previously undone edit |
| **Ctrl+X** | Cut | Cut selected text |
| **Ctrl+C** | Copy | Copy selected text |
| **Ctrl+V** | Paste | Paste from clipboard |
| **Ctrl+A** | Select All | Select entire document |
| **Ctrl+F** | Find | Open find dialog |
| **Ctrl+H** | Replace | Open find and replace dialog |

## TTS Generation

| Shortcut | Action | Description |
|----------|--------|-------------|
| **Ctrl+G** | Generate All | Generate audio for entire document |
| **Ctrl+P** | Preview Selection | Generate audio for selected text only |
| **Esc** | Stop Generation | Cancel ongoing TTS generation |

*Note: TTS shortcuts may vary based on menu configuration*

## Selection Toolbar

When text is selected, use these actions from the toolbar:

| Button | Action | Description |
|--------|--------|-------------|
| **Exclude** | Mark as Excluded | Skip this text during TTS generation |
| **Include** | Mark as Included | Include this text in TTS generation |
| **Preview** | Preview Audio | Generate and play audio for selection |
| **Stop** | Stop | Cancel generation |

*The selection toolbar appears automatically when text is selected (if enabled in Preferences)*

## View Controls

| Shortcut | Action | Description |
|----------|--------|-------------|
| **F11** | Toggle Fullscreen | Enter/exit fullscreen mode |
| **Ctrl++** | Zoom In | Increase editor font size |
| **Ctrl+-** | Zoom Out | Decrease editor font size |
| **Ctrl+0** | Reset Zoom | Return to default font size |

*Note: Zoom shortcuts may need to be configured in Preferences*

## Preferences

| Shortcut | Action | Description |
|----------|--------|-------------|
| **Ctrl+,** | Open Preferences | Open settings dialog |
| **F1** | Help Contents | Open this help system |

## Document Management

| Shortcut | Action | Description |
|----------|--------|-------------|
| **Delete** | Remove Document | Delete selected document from project |
| **Ctrl+Up** | Move Up | Move document up in playlist order |
| **Ctrl+Down** | Move Down | Move document down in playlist order |
| **Space** | Toggle Enabled | Enable/disable document in playlist |
| **Enter** | Document Settings | Open settings for selected document |
| **Drag & Drop** | Reorder | Drag documents to reorder playlist |

*Note: Document management shortcuts work when document list has focus*

## Navigation

### Within Dialogs

| Key | Action |
|-----|--------|
| **Tab** | Move to next field |
| **Shift+Tab** | Move to previous field |
| **Enter** | Activate default button (OK/Apply) |
| **Esc** | Close dialog (Cancel) |
| **Arrow Keys** | Navigate lists/tabs |
| **Space** | Toggle checkboxes |

### In Text Editor

| Key | Action |
|-----|--------|
| **Ctrl+Home** | Jump to start of document |
| **Ctrl+End** | Jump to end of document |
| **Home** | Jump to start of line |
| **End** | Jump to end of line |
| **Ctrl+→** | Move to next word |
| **Ctrl+←** | Move to previous word |
| **PgUp** | Scroll up one page |
| **PgDn** | Scroll down one page |

## Tips

1. **Discover shortcuts**: Hover over menu items to see shortcuts in parentheses
2. **Customize**: Some shortcuts may be configurable in future versions
3. **Platform differences**: On macOS, Cmd (⌘) typically replaces Ctrl
4. **Context-sensitive**: Some shortcuts only work in specific contexts
5. **Selection toolbar**: Enable/disable in **Edit → Preferences → General**
