# Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl+N | New Project |
| Ctrl+I | Import Document(s) |
| Ctrl+O | Open Document(s) (same as Import) |
| Ctrl+F | Find |
| Ctrl+Q | Quit |
| F1 | Help Contents |

Other actions have no shortcut. Use the menus or the toolbar buttons.
